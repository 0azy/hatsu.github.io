# Hatsu — páginas legales

Sitio estático con la portada, las Condiciones del Servicio y la Política de Privacidad de Hatsu.

## Activar GitHub Pages

En este repositorio, abre **Settings → Pages**. En **Build and deployment**, selecciona **Deploy from a branch**, elige la rama **main** y la carpeta **/(root)**, y guarda.

Al publicarse, la portada será:

`https://0azy.github.io/hatsu.github.io/`

En el perfil de la aplicación de Discord, usa:

- Condiciones: `https://0azy.github.io/hatsu.github.io/terms-of-service.html`
- Privacidad: `https://0azy.github.io/hatsu.github.io/privacy-policy.html`

GitHub Pages debe quedar habilitado en la configuración del repositorio antes de que esas direcciones respondan públicamente.
