Política de Privacidad

Esta política describe los datos que procesa Hatsu, un bot de seguridad y moderación para Discord en desarrollo, y cómo se manejan en la implementación actual.

1. Responsable y contacto

Operador del proyecto: 0azy. Contacto para consultas y solicitudes de privacidad: zyra.develops@gmail.com.

Hatsu se ejecuta en el equipo o servidor que aloja la instancia. Quien controla ese equipo puede acceder a sus archivos de registro y debe protegerlos y atender las solicitudes de los miembros del servidor.

2. Datos que procesa el bot

  • Contenido de mensajes: se procesa temporalmente en memoria para buscar enlaces y patrones de spam o estafa. La implementación actual no escribe el texto ni las URLs del mensaje en el archivo de registro.
  • Metadatos de moderación: cuando se detecta una coincidencia, el bot registra fecha y hora, identificadores del servidor, canal, miembro y mensaje, regla detectada, nivel de confianza y resultado de la acción.
  • Datos de Discord: el bot recibe de Discord la información necesaria para conectarse al servidor, leer los mensajes permitidos y ejecutar las acciones autorizadas.

3. Finalidades y almacenamiento

El contenido se procesa para detectar y retirar mensajes sospechosos y aplicar la configuración de moderación del servidor. Los metadatos de las acciones se guardan localmente, en el archivo hatsu-actions.jsonl de la instancia del bot, para que su operador pueda revisar qué ocurrió.

La implementación actual no tiene un plazo automático de borrado: los registros permanecen en el equipo que aloja el bot hasta que su operador los elimine. El administrador de esa instancia debe mantenerlos solo el tiempo necesario y borrar registros ante una solicitud válida. Para pedir la eliminación de un registro local, contacta primero al administrador del servidor que aloja Hatsu; también puedes escribir a zyra.develops@gmail.com.

4. Compartición y terceros

El código actual no envía el contenido de los mensajes a servicios de análisis, publicidad o inteligencia artificial. El bot usa la API de Discord para recibir mensajes y ejecutar las acciones de moderación configuradas. Discord trata los datos conforme a su propia Política de Privacidad.

Estas páginas están alojadas mediante GitHub Pages. GitHub registra y almacena la dirección IP de quien visita un sitio de GitHub Pages por motivos de seguridad; consulta la documentación de GitHub Pages y el Aviso de Privacidad de GitHub.

5. Seguridad

El contenido de los mensajes se procesa en memoria y no se guarda en los registros de la implementación actual. Los archivos de registro se encuentran bajo el control del operador de la instancia; protege el equipo, limita el acceso y no publiques esos archivos. Ningún sistema conectado a Discord puede garantizar riesgo cero.

6. Cambios y contacto

Actualizaremos esta política si cambia la forma en que Hatsu procesa datos. Última actualización: 8 de noviembre de 2026. Para consultas o solicitudes: zyra.develops@gmail.com.
