Política de Privacidad

Esta política describe los datos que procesa Hatsu, un bot de seguridad y moderación para Discord en desarrollo. Hatsu está diseñado para ejecutarse en una instancia bajo el control de la comunidad que lo aloja.

1. Responsable y contacto

Operador del proyecto: 0azy. Contacto: zyra.develops@gmail.com.

En una instalación autohospedada, el operador del equipo o servidor donde corre Hatsu controla los archivos locales y debe protegerlos y responder a solicitudes relacionadas con esos registros. El creador del proyecto no recibe automáticamente los datos de una instancia autohospedada.

2. Datos que procesa el bot

  • Contenido de mensajes y datos de embeds: se procesan temporalmente en memoria para detectar dominios y patrones sospechosos. Hatsu no guarda el texto, las URLs ni el contenido de embeds en sus registros.
  • Metadatos de moderación: cuando se detecta una coincidencia, se registran fecha y hora, servidor, miembro, canal o mensaje, regla, nivel de confianza y resultado de la acción.
  • Configuración del servidor: se guarda localmente el listado de dominios, los ajustes de antiraid y ban, y el ID del canal de avisos.
  • Panel OAuth: si el administrador activa el panel, Discord proporciona el ID y nombre de la cuenta, y la lista de servidores con sus permisos. El panel vuelve a consultar los permisos al abrir el panel y al guardar cambios.
  • Sesión del panel: el identificador de sesión, el token OAuth de Discord y los datos necesarios para el panel se mantienen solo en memoria durante un máximo de cuatro horas. El token no se escribe en disco. El navegador recibe una cookie firmada, HttpOnly, SameSite y, cuando se usa HTTPS, Secure.

3. Finalidad, almacenamiento y retención

Hatsu procesa mensajes para detectar y retirar spam o enlaces de estafa, ejecutar la configuración del servidor y permitir a los administradores consultar los ajustes y acciones recientes.

La configuración se guarda en data/guild-config.json. Los metadatos de moderación se guardan en archivos diarios separados por servidor dentro de data/audit/. Hatsu elimina los registros con más de 30 días al iniciar y cada 24 horas mientras está en ejecución. La configuración local permanece hasta que el operador la borra o elimina la instancia. Quien opera la instancia puede borrar antes esos archivos y debe atender las solicitudes válidas de eliminación.

Para solicitar la eliminación de un registro de una comunidad, contacta primero al administrador del servidor que aloja Hatsu. También puedes escribir a zyra.develops@gmail.com para preguntas o solicitudes relacionadas con el proyecto.

4. Compartición y servicios externos

El código actual usa la API de Discord para recibir mensajes, ejecutar acciones de moderación y autenticar a los administradores que eligen usar el panel. No envía el contenido de mensajes a servicios de análisis, publicidad o inteligencia artificial. Discord procesa datos conforme a su Política de Privacidad.

Estas páginas están alojadas mediante GitHub Pages. GitHub registra y almacena la dirección IP de quienes visitan un sitio de GitHub Pages por motivos de seguridad. Consulta la documentación sobre recopilación de datos de GitHub Pages y el Aviso de Privacidad de GitHub.

5. Seguridad

Los registros se separan por servidor y permanecen en el equipo que aloja el bot. Restringe el acceso al equipo, protege el token del bot y no publiques la carpeta de datos. El operador del proceso puede acceder al contenido de mensajes mientras Hatsu lo analiza; por eso el modo autohospedado es necesario si la comunidad quiere controlar directamente sus datos. Ningún sistema conectado a Discord puede garantizar riesgo cero.

6. Cambios y contacto

Actualizaremos esta política si cambia la forma en que Hatsu procesa datos. Última actualización: 8 de noviembre de 2026. Contacto: zyra.develops@gmail.com.
